# LongLLMLingua 小组复现

本仓库用于四人接力复现 LongLLMLingua，使用固定 NaturalQuestions 数据与 DeepSeek 官方 API。

第一阶段已通过本机技术验收，完整代码、配置、样本清单和真实结果位于 [stage1-foundation 分支](https://github.com/SPikerinbit/longllmlingua-reproduction/tree/stage1-foundation)，供队友复核后合并。

阶段分工：数据与基线 → 压缩方法 → 主实验与评估 → 消融与效率分析。

本仓库不包含密钥、完整数据、模型权重和预测缓存。
